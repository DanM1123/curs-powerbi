Interactivitate în rapoarte

Un raport bun nu doar afișează numere — permite audienței să-și răspundă singură la întrebări. Azi construim experiența: slicers, filtre multi-nivel, tooltip-uri îmbogățite, bookmarks și navigare.

Obiectivele lecției

  • Alegi tipul potrivit de slicer pentru fiecare context.
  • Înțelegi diferența între filtrele de nivel vizual / pagină / raport.
  • Controlezi interacțiunile dintre vizualizări (Edit interactions).
  • Construiești tooltip-uri cu pagină custom (rich tooltip).
  • Folosești bookmarks și selection pane pentru a crea stări alternative ale paginii.

Setări frecvente

Format → Slicer settings: Single select (radio) vs Multi-select. Include „Select all”? Orientare orizontală vs. verticală? Header „Nume câmp” vs. custom.

Sync slicers între pagini

Dacă vrei ca selecția dintr-un slicer pe pagina A să se aplice automat și pe pagina B: View → Sync slicers. Bifezi paginile țintă.

Filtre: vizual / pagină / raport

Panoul Filters are 3 nivele. Cunoaște-le diferența:

  1. Filtre de nivel vizual

    Se aplică doar la vizualizarea selectată. Nu afectează restul paginii.

  2. Filtre de nivel pagină

    Se aplică tuturor vizualizărilor de pe pagina curentă. Nu se văd ca slicer, sunt „ascunse” în panoul Filters.

  3. Filtre de nivel raport

    Se aplică tuturor paginilor din raport. Util: „Vreau să văd doar 2024 peste tot”.

Filtru ascuns (pt. consumator)

Butonul „ochi tăiat” ascunde filtrul — utilizatorul nu-l vede, dar se aplică. Foarte util ca să livrezi raport „curat”.

Tipuri de filtru avansate

  • Top N: afișează doar primele N valori.
  • Advanced: expresii de genul „conține”, „începe cu”, „nu este gol”.
  • Relative date / time: pentru perioade dinamice.

Edit interactions

Default: dacă apeși pe o bară, toate celelalte vizualizări se filtrează. Dar poți controla asta: Format → Edit interactions.

  • Filter (default la tabele): ascunde rândurile non-relevante.
  • Highlight (default la grafice): evidențiază porțiunea relevantă, menține restul gri.
  • None: vizualizarea nu reacționează.

Tooltips custom (rich tooltips)

Când plasezi mouse-ul peste o bară, default vezi numele + valoarea. Poți afișa însă o întreagă pagină Power BI ca tooltip.

  1. Creează o pagină nouă „Tooltip”

    Page Information → bifează Allow use as tooltip. Setează Page size = Tooltip.

  2. Construiește conținutul

    Pui acolo cardul + mini-grafic + text. Mic, compact.

  3. Atașează tooltip-ul la vizualizare

    Click pe vizualizarea-țintă → Format → Tooltip → Page → alegi pagina ta.

De ce să folosești

Hover-ul unui cursant devine un „mini raport”. Poți da mult context fără să aglomerezi pagina principală.

Bookmarks & Selection pane

Un bookmark este un „screenshot de stare”: memorează filtrele active, elementele vizibile/ascunse și selecțiile curente. Utilizezi pentru a crea:

Butoane „reset filters”

Un buton care aduce pagina la starea inițială.

Switch între vederi

Comutator grafic / tabel pe același card. Ascunzi unul, arăți altul.

Story-telling pas cu pas

Apeși „Next” și treci prin insights într-o ordine controlată.

Pop-up info

Un ecran overlay care apare peste pagină (ex: „ce înseamnă AOV?”).

Flux de lucru

  1. View → Selection pane + Bookmarks pane

    Deschizi ambele panouri.

  2. Ascunde elementele de care nu ai nevoie

    Click pe ochiul din Selection pane.

  3. Setează filtrele dorite

    Aplici filtre / slicere în starea pe care vrei s-o salvezi.

  4. Bookmarks → Add

    Se salvează starea. Redenumește cu un nume clar.

  5. Leagă un buton de bookmark

    Insert → Buttons. Format → Action → Type: Bookmark. Ctrl+Click în editor ca să testezi.

Mini-proiect

Raport interactiv complet

Pornind de la raportul existent, adaugă un strat complet de interactivitate.

Cerințe:

  • Minim 3 slicers + 2 filtre de nivel pagină.
  • 1 tooltip custom pe cea mai importantă vizualizare.
  • 2 bookmarks + butoane pentru a le declanșa.
  • 1 buton „Reset filters” care curăță toate selecțiile.
  • Ajustezi Edit interactions pe minim o vizualizare.
