Transformarea și curățarea datelor

Datele din lumea reală sunt „murdare”: lipsuri, duplicate, formate inconsistente. Power Query este uneltele cu care le faci perfect utilizabile înainte să construiești raportul.

Obiectivele lecției

  • Înțelegi diferența între date brute și date pregătite pentru analiză.
  • Navighezi cu încredere în Power Query Editor și folosești pașii aplicați (Applied Steps).
  • Aplici transformările cele mai folosite: tipuri de date, filtre, coloane calculate, split, replace.
  • Combini tabele prin Merge (JOIN) și Append (UNION).
  • Faci Pivot și Unpivot — două operațiuni pe care 90% din analiști le înțeleg greșit la început.
  • Citești codul M generat și îl ajustezi manual.

Ce este Power Query?

Power Query este „filtrul” prin care trec datele înainte să ajungă în modelul Power BI. Este un motor ETL (Extract → Transform → Load) ușor de folosit, cu UI, dar care în spate scrie cod M.

Regula de aur

Fă toate transformările în Power Query, nu direct în model sau în DAX. Modelul trebuie să primească date deja curate.

Principii

Repetabil

Pașii se execută identic la fiecare refresh.

Non-destructiv

Sursa originală nu este atinsă, toate transformările trăiesc în PBI.

Compozabil

Fiecare pas este o funcție — le combini ca LEGO.

Incremental

Adaugi un pas, vezi imediat rezultatul.

Interfața Power Query Editor

Deschizi editorul prin Home → Transform data. Patru zone de bază:

  1. Ribbon

    Toate transformările grupate pe tab-uri: Home, Transform, Add Column, View.

  2. Queries (stânga)

    Lista tuturor „query-urilor” (tabelelor) pe care le construiești. Poți face foldere.

  3. Preview (centru)

    Primele 1000 de rânduri din tabel, așa cum arată după fiecare pas.

  4. Applied Steps (dreapta)

    Lista pașilor aplicați, în ordine. Poți șterge, edita sau reordona oricând.

Transformările cele mai folosite

Tipuri de date (Data types)

Primul lucru după încărcare: verifică și setează tipul corect pentru fiecare coloană. Icoanele din antet arată tipul: 123 integer, 1.2 decimal, ABC text, 📅 date.

Atenție la locale

Virgule vs puncte pentru zecimale: setează corect Data Type → Using Locale când deschizi fișiere din altă regiune.

Filtre & sortare

Ca în Excel: click pe săgeata din antet. Poți filtra după valoare, după regulă („începe cu”, „conține”) sau între interval.

Filtrele din Power Query elimină rândurile din model — spre deosebire de slicer-ele din raport, care doar ascund vizual.

Split column & Replace values

Split column împarte o coloană după delimitator. Ex: „Ion Popescu” → „Ion” + „Popescu”.

Replace values înlocuiește toate aparițiile unei valori cu alta. Util pentru normalizare (ex: „RO”, „ROU”, „Romania” → „România”).

Coloane calculate

Add Column → Custom Column. Ex: calcul valoare netă dintr-o coloană brută:

M · formula
Table.AddColumn(#"Prev Step", "Valoare_Neta", each [Valoare_Bruta] * (1 - [Discount]))

Duplicate & null-uri

Remove duplicates păstrează doar valori unice pentru o coloană sau combinație de coloane. Replace / Remove errors / Remove blank rows — indispensabile pentru date murdare.

Pro tip

În Power Query: View → Column quality / distribution / profile. Îți arată procentul de valori goale, erori, unice.

Combinarea tabelelor: Merge & Append

Merge = JOIN (pe coloane)

Aduci coloane dintr-un tabel în altul, folosind o cheie comună. Ex: ID client din „Vânzări” + Nume din „Clienți”. Alegi tipul de join (inner, left, full).

Append = UNION (pe rânduri)

Lipești tabele cu aceeași structură unul sub altul. Ex: vânzări_2023 + vânzări_2024 → vânzări_consolidate.

Tipuri de Merge

TipComportamentCând îl folosești
Left OuterPăstrează toate din stânga, aduce potriviri din dreaptaDefault & cel mai sigur
InnerDoar potriviri din ambeleCând vrei strict intersecția
Left AntiDoar din stânga, fără potrivire în dreaptaDetectezi lipsuri (ex: clienți fără comenzi)
Full OuterToate din ambele tabeleReconcilieri complete

Pivot & Unpivot — regula de aur

În Power BI lucrezi cel mai bine cu date în format long / tidy: o coloană pentru categorie, o coloană pentru valoare. Multe fișiere Excel vin în format wide — trebuie să le unpivot-ezi.

❌ Format wide (greu)✅ Format long (preferat)
Produs | Ian | Feb | Mar
A | 100 | 120 | 90		 Produs | Lună | Valoare
A | Ian | 100
A | Feb | 120
A | Mar | 90
Unpivot în 2 click-uri

Selectezi coloanele Ian/Feb/Mar → Transform → Unpivot columns. Gata!

Limbajul M · privire rapidă

Fiecare pas din Applied Steps este o linie de cod M. Apăsând View → Advanced Editor vezi întregul script:

M · Advanced Editor 
let
    Source = Excel.Workbook(File.Contents("C:\Date\Vanzari.xlsx"), null, true),
    Sheet = Source{[Item="Vanzari",Kind="Sheet"]}[Data],
    PromoteHeaders = Table.PromoteHeaders(Sheet, [PromoteAllScalars=true]),
    ChangeTypes = Table.TransformColumnTypes(PromoteHeaders,{{"Data", type date}, {"Valoare", type number}}),
    FilterValide = Table.SelectRows(ChangeTypes, each [Valoare] > 0)
in
    FilterValide

Nu trebuie să-l scrii de la zero — UI-ul îl generează. Dar e util să-l înțelegi ca să poți depana și optimiza.

Mini-proiect

Consolidare reală

Găsește (sau creează) 3 fișiere Excel cu aceleași coloane — de exemplu export-uri lunare. Consolidează-le într-un singur tabel curat, folosind doar Power Query.

Cerințe:

  • Import 3 fișiere (sau un folder întreg cu Folder connector).
  • Curățare: tipuri, null-uri, duplicate.
  • Combinare cu Append.
  • Adaugă o coloană „Sursa” = numele fișierului de proveniență.
  • Final: tabel curat, ordonat după dată.
Bonus

Folosește conectorul Folder ca să adăugarea unui fișier nou în folder să se reflecte automat la refresh.
