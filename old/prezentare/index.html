Pasul 2 · Ce este Power BI

Power BI este platforma Microsoft pentru analiză de date. O aplicație care preia date dintr-o gamă largă de surse, le transformă în rapoarte interactive și le distribuie întregii organizații.

Ce face Power BI, în 3 etape:

1

Conectează

Excel, SQL Server, Azure, SharePoint, web, REST APIs, peste 100 de surse built-in.

→
2

Transformă

Date brute → vizualizări interactive: KPI-uri, grafice, hărți, dashboard-uri. Cu drag & drop.

→
3

Distribuie

Cloud, mobil, Teams, SharePoint, colegii deschid singuri, datele se actualizează automat.

Ecosistemul Power BI, 3 piese care lucrează împreună:

Construim
Desktop
Aplicație Windows gratuită, aici construim rapoartele.
Publicăm
Service
Cloud Microsoft, publicăm și colegii deschid din browser.
Consumăm
Mobile
App iOS/Android, consumăm rapoartele oriunde, oricând.
Pasul 3 · Cum arată Power BI Desktop

Tur ghidat al interfeței Power BI Desktop

Apasă butoanele din stânga ca să comuți între cele 3 panouri ale aplicației, apoi punctele galbene ca să afli ce face fiecare zonă.

REPORT VIEW

Apasă un punct galben pe imagine

Folosește butoanele din stânga imaginii pentru a comuta între cele 3 panouri ale aplicației (Report, Table, Model). Apoi apasă punctele galbene • pentru a vedea ce face fiecare zonă din interfață.

💡 Începe cu Report View, aici stăm 95% din timp.
R
Report View, canvas-ul de design. Aici construiești KPI-uri, grafice, slicere.
T
Table View, tabelul brut, ca în Excel. Verifici ce ai importat.
M
Model View, relații între tabele, prin drag & drop.

Acum știți cum arată. Imediat o deschidem live și exact aceleași zone le veți vedea în acțiune.

Pasul 4 · Construim împreună

Primul tău raport, în 5 click-uri

Cine are Power BI Desktop deschis, face în paralel. Cine nu, doar urmărește. Le poți folosi ca cheat-sheet când lucrezi singur acasă.

vanzari.csv 62 rânduri · ~5 KB

Date fictive de vânzări imobiliare 2024–2025, folosește acest fișier pentru a urma pașii live.

Data Tip casa Categorie Vanzari Profit Client
Descarcă CSV
  1. 1
    Conectare: Home → Get Data → Text/CSV → selectează vanzari.csv → Load
  2. 2
    Curățare rapidă: Transform Data → schimbă tipul coloanei Data în Date, iar Vanzari și Profit în Whole Number → Close & Apply
  3. 3
    Card cu suma: trage Vanzari pe canvas → click pe Card din panoul Visualizations
  4. 4
    Bar chart pe categorii: click pe canvas gol → Bar chart → axă: Categorie, valori: Vanzari
  5. 5
    Slicer pentru filtrare: click pe canvas gol → Slicer → câmp: Tip casa → click pe „Casa A" și vezi cum se filtrează totul ✨
